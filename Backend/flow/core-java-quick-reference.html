Core Java Quick Reference - Interview

Based on concepts in CoreJavaMastery | Updated: 2026-03-14

OOPs Basics

  • Four pillars: Encapsulation, Inheritance, Polymorphism, Abstraction.
  • Encapsulation: private fields + getters/setters (data hiding).
  • Inheritance: reuse via extends; promotes is-a relation.
  • Polymorphism: method overriding + dynamic dispatch.
  • Abstraction: abstract class vs interface (contracts).

Classes & Modifiers

  • final class cannot be extended; final method not overridden.
  • static members belong to class, not instance.
  • Interfaces can have default and static methods (Java 8+).
  • Constructors: no return type, used for initialization.
  • Singleton pattern: private constructor + static instance getter.

String Concepts

  • String is immutable and final.
  • Literal strings stored in String Constant Pool.
  • == compares references; equals() compares content.
  • StringBuilder is mutable, fast, not thread-safe.
  • StringBuffer is mutable, thread-safe, slower.

Exceptions

  • Exception disrupts normal flow; handled with try-catch-finally.
  • Checked: compile-time (e.g., IOException).
  • Unchecked: runtime (e.g., NullPointerException).
  • finally executes regardless of exception.
  • Custom exceptions by extending RuntimeException or Exception.

Multithreading

  • Thread is a lightweight process; use Thread or Runnable.
  • Life cycle: New -> Runnable -> Running -> Terminated.
  • sleep(ms) pauses current thread; does not release lock.
  • join() waits for another thread to finish.
  • wait() releases lock; notify() wakes one waiting thread.

Collections Overview

  • Collection root interface (List, Set, Queue).
  • Collections utility class: sort, reverse, shuffle, max, min.
  • Best practice: program to interface (List vs ArrayList).
List allows duplicates; Set ensures uniqueness; Queue is FIFO.

List Implementations

  • ArrayList: dynamic array, fast access, allows nulls/duplicates.
  • LinkedList: doubly linked, faster insert/delete in middle.
  • Vector: synchronized, thread-safe, slower.
  • Generic list is type-safe; raw list allows mixed types.

Set Implementations

  • HashSet: unique, no order, allows one null.
  • LinkedHashSet: unique + insertion order.
  • TreeSet: sorted, no duplicates, typically no null.

Queue

  • PriorityQueue: head is smallest by natural order.
  • offer() inserts, poll() removes head.

Map Basics

  • Stores key-value pairs; keys are unique.
  • Views: keySet(), values(), entrySet().
  • HashMap uses buckets; collisions handled by list/tree.
  • LinkedHashMap preserves insertion order.
  • TreeMap keeps keys sorted.

Comparable vs Comparator

  • Comparable: natural ordering via compareTo.
  • Comparator: external ordering, supports multiple sort keys.
  • Use Comparator when sorting by salary, name, date, etc.

Java 8: Lambda & Streams

  • Lambda: concise implementation of functional interfaces.
  • Functional interfaces: Predicate, Function, Consumer, Supplier, Runnable.
  • Streams: filter, map, collect for data processing.
  • Example: list.stream().filter(x -> x % 2 == 0).collect(...).

IO & Serialization

  • File represents file or directory path.
  • Streams: FileInputStream / FileOutputStream.
  • Serializable for object to byte-stream conversion.
  • Externalizable gives manual control of serialization.

Common Coding Rounds

  • First non-repeated character in a string.
  • Second highest number in array.
  • Factorial, selection sort, matrix multiplication.
  • Even numbers with streams vs loops.
  • Pattern printing (right-angled triangle).
