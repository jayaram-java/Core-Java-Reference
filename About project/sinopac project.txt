In my recent project, I worked on a react and typescript based digital banking application,
and my main focus was the send money and beneficiary management modules.

In send money, I implemented a complete transaction flow from recipient selection to transfer confirmation.
the key part i owned was OTP- based verification. where we first generate otp , validate it and only then
allow payment createion.


I handled input validation, step-by-step state transitons and API orchestration so the flow remains secure
and smooth even when network errors happen.

In beneficiary management, I worked on adding and managing beneficiaries with clear form validation
and confirmation steps. I also ensured users can quickly choose existing beneficiaries during transfer
which improved speed and usability.
