JavaScript Interview Cheat Sheet

Quick, high-signal reminders for common interview topics.

Basics

  • var function-scoped, hoisted (initialized as undefined).
  • let/const block-scoped, temporal dead zone.
  • Primitive types: string, number, bigint, boolean, undefined, symbol, null.
  • typeof null is "object" (legacy quirk).
  • Strict equality === avoids coercion.

Hoisting & Scope

  • Function declarations hoist fully; function expressions hoist the variable only.
  • Lexical scope: functions remember the scope where they are created.
  • Global: window (browser) / global (Node).
console.log(a) // undefined
var a = 1
// let a = 1 would throw ReferenceError

Closures

  • Function + its lexical environment captured.
  • Used for data privacy, factories, memoization.
function counter() {
  let n = 0
  return () => ++n
}
const c = counter()

This & Binding

  • Default: this is global (non-strict) or undefined (strict).
  • Method call: obj.fn() sets this to obj.
  • Arrow functions: no own this, lexical.
  • Explicit: call, apply, bind.

Objects & Prototypes

  • Every object has internal [[Prototype]] link.
  • Prototype chain resolves property lookups.
  • Object.create(proto) creates with given prototype.
  • class is syntactic sugar over prototypes.

Functions

  • First-class: pass/return/store like values.
  • Higher-order functions: accept or return functions.
  • IIFE: immediately invoked function expression.
  • Arrow functions: concise syntax, lexical this, no arguments.
const add = (a, b) => a + b

(function () {
  // init
})()

Array Methods

  • map transforms, same length.
  • filter selects subset.
  • reduce aggregates to single value.
  • find returns first match, some/every boolean checks.
  • slice non-mutating, splice mutating.

Async JS

  • Event loop: call stack + task/microtask queues.
  • Promises: then/catch/finally.
  • async/await is syntax over promises.
async function getData() {
  try {
    const res = await fetch(url)
    return await res.json()
  } catch (e) {
    console.error(e)
  }
}

Common Pitfalls

  • [] == false is true (coercion).
  • Floating point: 0.1 + 0.2 !== 0.3.
  • Mutating arrays/objects can cause side effects.

DOM & Events

  • Event bubbling vs capturing.
  • Use event delegation for lists.
  • preventDefault stops default behavior.

Modules

  • ESM: import/export with static analysis.
  • CommonJS: require/module.exports.

Performance

  • Debounce vs throttle for event-heavy UI.
  • Avoid layout thrashing: batch DOM reads/writes.
  • Use requestAnimationFrame for animations.

Interview Prompts

  • Explain event loop with microtasks.
  • Code deep clone function.
  • Compare var vs let vs const.
  • Build promise polyfill basics.
Tip: use examples + edge cases in answers.
