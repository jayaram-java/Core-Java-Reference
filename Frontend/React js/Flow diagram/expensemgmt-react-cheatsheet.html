ExpenseMgmt React Cheat Sheet

Beginner interview-ready summary of Hooks, Router, Props, and the Container/Presenter pattern used in the project.

Project paths used: src/features/login, src/features/dashboard, src/components.

1) Hooks Cheat Sheet

useState Local state

Store and update component state.

const [email, setEmail] = useState('')
setEmail('student@example.com')

Used in Login and Dashboard containers.

useEffect Side effects

Run code when component mounts or dependencies change.

useEffect(() => {
  document.title = 'Login | Expense Manager'
}, [])

Used for title updates and localStorage sync.

useMemo Derived values

Memoize expensive computations.

const total = useMemo(() =>
  expenses.reduce((sum, e) => sum + e.amount, 0)
, [expenses])

Used to compute the dashboard total.

2) React Router Cheat Sheet

Routes live in src/App.tsx. Main paths: / (Login) and /dashboard (Dashboard). 

<BrowserRouter>
  <Routes>
    <Route path="/" element={<LoginContainer />} />
    <Route path="/dashboard" element={<DashboardContainer />} />
  </Routes>
</BrowserRouter>

useNavigate

Programmatic navigation (login, logout).

const navigate = useNavigate()
navigate('/dashboard')

useLocation

Read router state (passed userName).

const location = useLocation()
const name = location.state?.userName

3) Props Cheat Sheet

Props are data passed from parent to child. The project uses a Container (logic/state) + Presenter (UI) split. 

// Container passes props to Presenter
<LoginPresenter
  email={email}
  password={password}
  onEmailChange={setEmail}
  onSubmit={handleSubmit}
/>

Container

  • Owns state and hooks
  • Handles events and side effects
  • Passes data + handlers as props

Presenter

  • Receives props only
  • Renders UI
  • Calls handlers on user actions

4) Component Pattern Used

Reusable components: Header and Footer live in src/components. They receive props like userName and onLogout. 

// Header props
<Header title="Expense Manager" userName={userName} onLogout={onLogout} />

5) Typical Usage Flow

Flow: Login -> navigate -> Dashboard -> Logout -> Login.

7) One-Minute Summary

The app uses React Router for page navigation. Each page has a Container for state + hooks and a Presenter for UI. State is handled with useState, side effects with useEffect, and derived totals with useMemo. Reusable components (Header/Footer) receive props and display data without owning state.
